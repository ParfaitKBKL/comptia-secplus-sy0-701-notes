# 5.4 - Security Compliance

**Official CompTIA SY0-701 objective:** 5.4 - Summarize elements of compliance.
**Recommended resource:** Professor Messer SY0-701 - "Compliance", "Privacy Regulations" (Domain 5, Section 5.4)

---

## Compliance Reporting

| Type | Description |
|---|---|
| **Internal** | Regular reports to management on compliance posture |
| **External** | Required by regulators (HIPAA, PCI DSS, GDPR) |

---

## Consequences of Non-Compliance

| Consequence | Example |
|---|---|
| **Fines** | GDPR: up to 4% of global annual revenue or 20M EUR (whichever is higher) |
| **Sanctions** | Government-imposed restrictions |
| **Reputational damage** | Public breach disclosure, media coverage |
| **License revocation** | A healthcare facility loses its operating license |
| **Contractual impacts** | Contract breach with clients requiring compliance |

---

## Compliance Monitoring

| Activity | Description |
|---|---|
| **Due diligence/care** | Ongoing effort to maintain compliance - not a one-time event |
| **Attestation** | Formal declaration confirming compliance (signed by responsible party) |
| **Internal and external monitoring** | Internal audits + external reviews |
| **Automation** | Continuous compliance checks via tools (SCAP, AWS Config, Azure Policy) |

---

## Privacy Regulations

| Regulation | Scope |
|---|---|
| **GDPR** (General Data Protection Regulation) | Data of EU citizens - global applicability |
| **CCPA** (California Consumer Privacy Act) | California residents |
| **HIPAA** (Health Insurance Portability and Accountability Act) | US health data (PHI - Protected Health Information) |
| **PCI DSS** (Payment Card Industry Data Security Standard) | Payment card data |
| **GLBA** (Gramm-Leach-Bliley Act) | US personal financial data |
| **SOX** (Sarbanes-Oxley Act) | Financial controls for publicly traded US companies |

### Key GDPR Concepts

| Concept | Definition |
|---|---|
| **Data subject** | The individual whose data is being processed |
| **Controller** | Decides *why* and *how* data is processed |
| **Processor** | Processes data on behalf of the controller |
| **Right to be forgotten** | Individual can request deletion of their data |
| **Data sovereignty** | Data is subject to the laws of the country where it is stored |
| **Data inventory and retention** | Document what data exists, where, and for how long |
| **Breach notification** | Notify authorities within 72 hours of discovering a breach |

## Practice Questions

**Q: A US organization processes data of French citizens. What regulation applies?**
Answer: **GDPR** - applies whenever data of EU citizens/residents is processed, regardless of the organization's location.

**Q: An organization experiences a data breach. Under GDPR, within what timeframe must it notify the competent authority?**
Answer: **72 hours** after discovering the breach.

**Q: What regulation applies to a US hospital storing the medical records of its patients?**
Answer: **HIPAA** - applies to covered entities processing PHI (Protected Health Information).
