# 5.6 - Security Awareness Practices

**Official CompTIA SY0-701 objective:** 5.6 - Given a scenario, implement security awareness practices.
**Recommended resource:** Professor Messer SY0-701 - "Security Awareness", "Phishing" (Domain 5, Section 5.6)

---

## Phishing Awareness

### Simulated Phishing Campaigns

- Send fake phishing emails to employees
- Track click rates, credential entry, reporting rates
- **Train** those who fall for it - do not punish

### Recognizing a Phishing Attempt

- Urgent language or fear-based messaging
- Unexpected sender or spoofed display name
- Mismatched or suspicious URLs (hover before clicking)
- Requests for credentials, payment, or sensitive information
- Grammar/spelling errors (less reliable now with AI)

### Responding to a Suspicious Message

1. **DO NOT click** on links or open attachments
2. **Report** via the organization's mechanism (Phish Alert button, email to the security team)
3. **Document and preserve** the email (do not delete it)

## Recognizing Abnormal Behavior

Employees should recognize and report:

| Behavior | Risk |
|---|---|
| **Risky** | Intentional violation - sharing credentials, unauthorized USB use |
| **Unexpected** | Normal user doing unusual things - possible account compromise |
| **Unintentional** | Errors without malicious intent - misconfiguration, wrong attachment |

## User Training Topics

| Topic | Why it matters |
|---|---|
| **Policy/handbooks** | Know the rules - ignorance is not a defense |
| **Situational awareness** | Recognize in-person social engineering attempts |
| **Insider threat** | Know the indicators - report concerning behaviors |
| **Password management** | Use a password manager, unique passwords, MFA |
| **Removable media** | Never plug in a found USB drive |
| **Social engineering** | Understand manipulation techniques |
| **OPSEC** (Operational Security) | Protect sensitive information from inadvertent disclosure |
| **Hybrid/remote work** | Home network risks, public Wi-Fi, screen privacy |

## Security Awareness Program

### Program Structure

```
Develop -> Deploy -> Monitor -> Improve
```

| Step | Description |
|---|---|
| **Initial training** | Onboarding - every new employee |
| **Recurring training** | Minimum annually; triggered after incidents |
| **Development** | Adapt content to role and risk level |
| **Execution** | LMS, phishing simulations, in-person workshops |

### Measuring Effectiveness

| Measure | Description |
|---|---|
| Phishing click rate | Before and after training |
| Employee-reported incidents | Increase = better security culture |
| Policy acknowledgment rate | Mandatory training completion rate |
| Security assessment scores | Pre/post knowledge test |

---

## Key Principle

> **People are both the weakest and strongest security control.**

Technical controls can be bypassed. A well-trained employee who recognizes a spear-phishing call and reports it can prevent a breach that no firewall would have stopped.

---

## Practice Questions

**Q: An organization sends fake phishing emails to its employees to test their resilience. 30% of employees click the link. What action should follow?**
Answer: **Targeted training** for those who clicked - not disciplinary action. The goal is improvement, not punishment. A 30% rate is an indicator of a training need.

**Q: An employee notices that a colleague is copying confidential files to a personal USB drive late at night. What type of behavior is this and what should they do?**
Answer: **Risky / insider threat** behavior - they should **report it** to the security team through the official reporting mechanism.
