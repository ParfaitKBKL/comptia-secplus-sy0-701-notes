## Firewall Configuration

Key configuration elements:
- **Rules:** Permit/deny based on source, destination, port, protocol
- **Access lists:** Ordered list of rules - **first match wins**
- **Ports/protocols:** Block unused ones; default deny
- **Screened subnet (DMZ):** Buffer zone between the internet and the internal network

> **Implicit deny:** every properly configured firewall ruleset ends with "deny all" - anything not explicitly permitted is denied. This is the fundamental principle.

| | IDS | IPS |
|---|---|---|
| Placement | Out-of-band (copy of traffic) | Inline (traffic passes through) |
| Response | Alert only | Alert + Block |

**Detection methods:**

| Method | Description | Pros/Cons |
|---|---|---|
| **Signature-based** | Known attack patterns | Fast, low FP, misses zero-days |
| **Anomaly-based** | Deviation from baseline | Detects unknowns, higher FP rate |

## Email Security

| Control | Function |
|---|---|
| **SPF** (Sender Policy Framework) | Authorizes sending servers for a domain - verifies the sender's IP |
| **DKIM** (DomainKeys Identified Mail) | Cryptographic signature on outgoing email - verifies authenticity |
| **DMARC** | Policy for handling SPF/DKIM failures - reject, quarantine, or report |
| **Email gateway** | Filters spam, malware, phishing before reaching the inbox |

### Email Authentication Chain

```
Receiving server checks SPF -> Did this server have permission to send?
    |
Receiving server checks DKIM -> Is the signature valid?
    |
DMARC policy -> If either fails, what to do? (none / quarantine / reject)
```

> **SPF + DKIM + DMARC = recommended combination**. DMARC alone without SPF/DKIM has no value. All three together drastically reduce email spoofing.

## DNS Filtering

Block malicious domains at the DNS resolution level - before the connection is established.

**Use case:** Block C2 (Command and Control) domains, malware distribution, phishing sites.

**Advantage:** Even if a user clicks a malicious link, if the domain is blocked by the DNS resolver, the connection is never established.

**Solutions:** Cisco Umbrella, Cloudflare Gateway, Pi-hole.

## Practice Questions

**Q: An attacker sends emails impersonating a bank's domain. The bank has configured SPF and DKIM but not DMARC. Spoofed emails still pass through. Why?**
Answer: Without **DMARC**, there is no policy defining what to do when SPF/DKIM fails. The receiving server does not know whether to reject or allow the message. DMARC is the policy that ties SPF and DKIM together.

**Q: What technology can detect unauthorized changes to operating system binary files?**
Answer: **FIM (File Integrity Monitoring)** - compares a cryptographic hash of the current file against the known baseline.

**Q: Which web filtering method works even when the user is off the corporate network (remote work)?**
Answer: **Agent-based web filtering** - the agent is installed on the endpoint and enforces the policy regardless of the network.
