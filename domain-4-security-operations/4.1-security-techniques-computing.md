# 4.1 - Security Techniques for Computing Resources

**Recommended resource:** Professor Messer SY0-701 - "Secure Baselines", "Hardening", "Mobile Solutions" (Domain 4, Section 4.1)

## Secure Baselines

A **secure baseline** defines the minimum acceptable security configuration for a given system type.

| Step | Description |
|---|---|
| **Establish** | Define configuration standards (CIS Benchmarks, DISA STIGs) |
| **Deploy** | Apply the baseline at provisioning time (IaC, GPO, MDM, automation scripts) |
| **Maintain** | Continuously enforce via configuration management and drift detection |

> **Configuration drift:** gradual deviation of a system from its secure baseline. Detected by configuration management tools (Ansible, Puppet, Chef, Desired State Configuration).

## Hardening Targets

| Target | Key hardening steps |
|---|---|
| **Mobile devices** | MDM enrollment, encryption, remote wipe, screen lock, disable Bluetooth/NFC if unused |
| **Workstations** | AV/EDR, FDE (BitLocker), host firewall, remove local admin rights |
| **Switches** | Disable unused ports, 802.1X, BPDU guard, VLAN separation, disable CDP/LLDP if unused |
| **Routers** | Disable unused protocols (Telnet to SSH), ACLs, routing protocol authentication |
| **Cloud infrastructure** | Minimal IAM permissions, security groups, logging enabled, MFA on console |
| **Servers** | Patch, disable unnecessary services, audit logging, host firewall, disable default accounts |
| **ICS/SCADA** | Network isolation, monitoring, no direct internet access, compensating controls |
| **Embedded systems** | Firmware updates, physical security, network isolation |
| **RTOS** | Isolation, monitoring - cannot be patched like a standard OS |
| **IoT** | Change default credentials, segment on a dedicated VLAN, disable UPnP |

## Mobile Solutions

### MDM (Mobile Device Management)

Centrally manages configuration, applications, and policies on mobile devices.

**MDM capabilities:**
- **Remote wipe** - delete all data in case of loss or theft
- **Enforce PIN/biometrics** - mandatory screen lock
- **Certificate deployment** - 802.1X authentication, email S/MIME
- **App allow/deny listing** - control which applications are permitted
- **Geofencing** - trigger actions based on location (disable camera in secure zones)
- **Containerization** - separate work data from personal data

### Mobile Deployment Models

| Model | Ownership | Security control level |
|---|---|---|
| **BYOD** (Bring Your Own Device) | Employee | Low - personal privacy limits control |
| **COPE** (Company-Owned, Personally Enabled) | Company | High - company controls the device |
| **CYOD** (Choose Your Own Device) | Company | Medium - employee chooses from an approved list |

## Wireless Security

| Protocol | Status | Notes |
|---|---|---|
| **WEP** | **Broken - never use** | RC4 key reused, crackable in minutes |
| **WPA** | **Deprecated** | Vulnerable, replaced by WPA2 |
| **WPA2** | Acceptable - still widely deployed | CCMP/AES, vulnerable to KRACK attacks (offline dict.) |
| **WPA3** | **Current standard** | SAE replaces PSK, resistant to offline dictionary attacks |

**Wi-Fi Enterprise:** uses 802.1X/RADIUS - authenticates with individual credentials, no shared PSK. If an employee leaves, revoke their account, not the whole office's shared password.

**SAE (Simultaneous Authentication of Equals)** in WPA3: the key exchange cannot be recorded for a later offline attack.

## Application Security Controls

| Control | Description |
|---|---|
| **Input validation** | Sanitize all user input - prevents injection attacks (SQLi, XSS, command injection) |
| **Secure cookies** | `HttpOnly` flag (no JS access) + `Secure` flag (HTTPS only) + `SameSite` (CSRF protection) |
| **SAST** (Static Application Security Testing) | Static code analysis before deployment |
| **DAST** (Dynamic Application Security Testing) | Testing the running application (OWASP ZAP, Burp Suite) |
| **Code signing** | Cryptographic signature to guarantee code integrity |
| **Sandboxing** | Isolate the execution environment of an application - limits blast radius |

## Practice Questions

**Q: An employee uses their personal iPhone to access company email. IT can remotely wipe only the work data without touching personal data. What deployment model and feature is this?**
Answer: **BYOD** with **MDM containerization** - separates work data from personal data.

**Q: What key improvement does WPA3 bring over WPA2 regarding password security?**
Answer: **SAE (Simultaneous Authentication of Equals)** - prevents offline dictionary attacks even if traffic is captured.

**Q: A new web server is deployed with default settings. What are the two first hardening actions to perform?**
Answer: **Change all default credentials** + **apply all available patches**.
