# 2.4 - Indicators of Malicious Activity

**Official CompTIA SY0-701 objective:** 2.4 - Given a scenario, analyze indicators of malicious activity.
**Recommended resource:** Professor Messer SY0-701 - "Malware", "Network Attacks", "Application Attacks" (Domain 2, Section 2.4)

## Malware Types

| Malware | Behavior | Key Identifier |
|---|---|---|
| **Ransomware** | Encrypts files, demands payment | Mass file modifications, shadow copy deletion, unknown file extension |
| **Fileless virus** | Loads entirely into **memory** - no file written to disk | High memory usage, no detectable executable, LOLBins active |
| **Trojan horse** | Masquerades as legitimate software but contains hidden malicious code | Unexpected network connections from a legitimate-looking app |
| **RAT (Remote Access Trojan)** | Type of Trojan granting unauthorized remote access to the compromised system | Persistent connections to a C2, activity at unusual hours |
| **Worm** | Autonomous program spreading across the network without user action | Lateral movement, network scanning from an endpoint, bandwidth consumption |
| **Spyware** | Collects user information without consent | Unusual data exfiltration, keystroke recording |
| **Keylogger** | Records all keystrokes | Keyboard input capture, credential theft |
| **Logic bomb** | Executed by a specific event or condition (date, time, action) | Difficult to detect before triggering - look in scheduled scripts |
| **Rootkit** | Hides itself and other malware in the OS | Missing processes in task manager, altered system binaries, difficult to detect from the infected OS |
| **Bloatware** | Pre-installed software by manufacturer/reseller without consent | Performance degradation, unnecessary data collection |
| **PUP (Potentially Unwanted Program)** | Program often installed without clear consent, impacts performance, privacy, and security | Similar behavior to bloatware, may install additional adware |
| **Computer virus** | Attaches to an executable, replicates when the host is run | Modified executables, triggered on execution |
| **RFID cloning** | Copies data from an RFID tag to another device | Used to clone access cards |

## Attack Categories

### Network Attacks

| Attack | Description | Indicators |
|---|---|---|
| **DDoS - Amplified** | Small request > large response (DNS, NTP amplification) - uses a spoofed source IP | Massive inbound traffic, suspicious DNS/NTP requests |
| **DDoS - Reflected** | Traffic bounced off a legitimate third party toward the victim | Multiple sources, stateless protocols (UDP) |
| **DNS hijacking** | Redirecting to malicious DNS servers | Incorrect DNS resolution, invalid certificates |
| **DNS cache poisoning** | Injecting falsified DNS records into the cache | DNS resolution pointing to unexpected IPs |
| **DNS tunneling** | Encoding data in DNS queries/responses to exfiltrate data or C2 | Abnormally high volume of DNS requests, very long domain names |
| **On-path (MitM)** | Attacker intercepts/modifies traffic between two parties | ARP poisoning, invalid certificates, suspicious SSL/TLS traffic |
| **Credential replay** | Captured valid credentials or tokens reused to authenticate | Connections from unusual locations, after-hours activity |
| **Evil Twin AP** | Malicious AP impersonating a legitimate AP | Two identical SSIDs with different MACs |
| **Deauth attack** | Sending deauthentication frames to disconnect clients | Repeated Wi-Fi disconnections |

### Application Attacks

| Attack | Description |
|---|---|
| **Injection** | SQLi, XSS, command injection, LDAP injection - malicious data in unvalidated inputs |
| **Buffer overflow** | Overwrite memory to redirect execution |
| **Replay** | Capture and re-submit valid authentication data |
| **Privilege escalation** | Vertical (gain admin rights) or horizontal (access another user's data) |
| **CSRF** | Force an authenticated user to make an unwanted request |
| **Directory traversal** | `../../etc/passwd` - escape web root to access the filesystem |

### Cryptographic Attacks

| Attack | Description |
|---|---|
| **Downgrade** | Force negotiation to a weaker protocol (POODLE on SSLv3, BEAST on TLS 1.0) |
| **Collision** | Find two inputs producing the same hash - breaks integrity |
| **Birthday attack** | Exploits the probability that two messages share a hash (birthday paradox) |

### Password Attacks

| Attack | Description | Defense |
|---|---|---|
| **Password spraying** | One password tried against many accounts - avoids lockout | MFA, authentication pattern detection |
| **Brute force** | Every possible combination tried - triggers lockout on weak policies | Lockout policy, MFA |
| **Dictionary attack** | Wordlist-based guessing | Long unique passwords |
| **Rainbow table** | Precomputed hash table for password cracking | Salting - renders rainbow tables useless |

### Physical Attacks

| Attack | Description |
|---|---|
| **Physical brute force** | Breaking locks, doors physically |
| **RFID cloning** | Copy access card data with a handheld reader |
| **Environmental** | Disrupt HVAC/power to cause hardware failure |
| **Tailgating/Piggybacking** | Follow someone into a secured area without authenticating |
| **Dumpster diving** | Search trash for sensitive documents |
| **Shoulder surfing** | Watch someone enter their credentials |

## Indicators of Compromise (IoCs)

Behavioral signals observed during/after an attack:

| Indicator | What it suggests |
|---|---|
| **Account lockout** | Brute force or password spray in progress |
| **Concurrent session usage** | Credential theft - attacker and user both active |
| **Blocked content** | DLP or proxy detecting an exfiltration attempt |
| **Impossible travel** | Login from New York then Paris 1 hour later - credential compromise |
| **Resource consumption** | CPU/memory/bandwidth spike - cryptominer, DDoS botnet participation |
| **Resource inaccessibility** | Ransomware currently encrypting, or active DoS |
| **Out-of-cycle logging** | Log entries at 3am when no admins work - lateral movement |
| **Published/documented CVE** | A public exploit is available - expect immediate scanning/exploitation |
| **Missing logs** | Attacker covering their tracks - audit log tampering |
| **New admin accounts** | Attacker creating a backdoor for persistent access |
| **Unusual outbound traffic** | Data exfiltration or C2 communication |

> **Blue team note:** Impossible travel and concurrent sessions are high-fidelity indicators for identity-based attacks. Missing logs require immediate investigation - normal users do not clear logs.

## Practice Questions

**Q: An analyst notices a server's CPU is at 100% overnight, with outbound connections to unknown IPs. What type of malware is most likely responsible?**
Answer: **Cryptomining malware** - uses system resources to mine cryptocurrency, connects to mining pools.

**Q: Malware loads only into RAM and writes no files to disk. What type is it?**
Answer: **Fileless malware** - very difficult to detect by traditional signature-based antivirus.

**Q: A user authenticates from Paris at 9am, then from Tokyo at 10am. What IoC is observed?**
Answer: **Impossible travel** - indicates likely credential theft or a connection through a VPN/proxy masking the real location.
