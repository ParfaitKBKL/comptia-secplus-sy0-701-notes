# 2.2 - Threat Vectors and Attack Surfaces

**Official CompTIA SY0-701 objective:** 2.2 - Explain common threat vectors and attack surfaces.
**Recommended resource:** Professor Messer SY0-701 - "Threat Vectors", "Social Engineering" (Domain 2, Section 2.2)

## Message-Based Vectors

| Vector | Attack Examples |
|---|---|
| **Email** | Phishing, malicious attachments, BEC (Business Email Compromise), Office macros |
| **SMS** | Smishing (SMS phishing) |
| **Instant Messaging (IM)** | Malicious links in Teams/Slack/Discord, malware distribution, account hijacking |

---

## File and Image-Based Vectors

- **Files:** Malicious Office macros, PDF exploits, ZIP bombs, archives containing scripts
- **Images:** Steganography (malware hidden in an image), malformed image parser exploits
- **Configuration files:** Malicious YAML/JSON exploiting vulnerable parsers

---

## Network Attack Surfaces

| Surface | Primary Risk |
|---|---|
| **Wireless** | Rogue AP (Evil Twin), deauthentication attacks, WPA cracking, KRACK |
| **Wired** | ARP spoofing, 802.1X bypass, Man-on-the-wire |
| **Bluetooth** | Bluejacking (unsolicited messages), Bluesnarfing (data theft), Blueborne (remote exploitation) |
| **NFC** | Eavesdropping, data interception, replay attacks, DoS attacks |
| **Unnecessary open ports** | Every unneeded open port = attack surface |
| **Default credentials** | Most IoT/router attacks exploit unchanged default passwords |

## Software Vulnerabilities

| Type | Description |
|---|---|
| **Client-based** | Software installed on the endpoint (browser plugin, thick client) - endpoint-managed surface |
| **Agentless** | Web application, no local install - server-side vulnerabilities |
| **Unsupported systems** | No patches available - known CVEs cannot be remediated |
| **Legacy applications** | Old codebases with technical debt, poor security posture |

---

## Supply Chain Attacks

Attack targeting the chain of trust between vendor and customer.

| Target | Real Example |
|---|---|
| **MSP** (Managed Service Provider) | Kaseya VSA attack (2021) - ransomware pushed to 1500+ businesses via their MSP |
| **Software vendor** | SolarWinds (2020) - malicious update pushed to 18,000+ organizations |
| **Hardware vendor** | Malicious chips in network hardware, backdoored firmware |
| **Open-source library** | npm `event-stream` package (2018) - malicious code injected in a popular dependency |

> Supply chain attacks are high-impact because they **abuse existing trust relationships** - the update comes from a legitimate server, signed with a valid certificate.

---

## Removable Devices

- **USB drops:** Attacker leaves a malicious USB drive in a parking lot, meeting room
- **BadUSB:** Reprogram a USB controller to emulate a keyboard (HID spoofing) - executes commands on connection
- **Autorun:** Automatic malware execution on insertion
- **Mitigation:** Disable autorun, block USB via GPO/MDM, endpoint DLP

## Human Vectors / Social Engineering

| Technique | Description |
|---|---|
| **Phishing** | Fraudulent email to steal credentials or deploy malware |
| **Vishing** | Voice call phishing (fake IT support, fake tax authority) |
| **Smishing** | SMS phishing |
| **Spear phishing** | Targeted phishing against a specific person or org - personalized |
| **Whaling** | Spear phishing targeting executives (CEO, CFO, CISO) |
| **Pretexting** | Creating a fabricated scenario to extract information ("I'm from IT, I need your password to fix your account") |
| **Impersonation** | Posing as a trusted entity (IT support, colleague, delivery person) |
| **BEC (Business Email Compromise)** | Impersonating an executive to authorize fraudulent wire transfers |
| **Watering hole** | Compromising a website the target frequently visits |
| **Brand impersonation** | Fake Microsoft/Apple/bank login pages |
| **Typosquatting** | Registering domains with common typos (`arnazon.com`, `micosoft.com`) |
| **Misinformation/Disinformation** | False information spread at scale - social manipulation |

### Social Engineering Success Factors

| Factor | How it is exploited |
|---|---|
| **Authority** | Posing as someone with power (CEO, IT, police) |
| **Urgency** | "You must act NOW or your account will be deleted" |
| **Scarcity** | "Limited time offer" |
| **Social proof** | "Everyone else has already done this" |
| **Familiarity/Liking** | Building rapport before the ask (LinkedIn reconnaissance) |
| **Intimidation** | Threatening negative consequences |
| **Trust** | Email appearing to come from a known sender |

> **Best defense against social engineering:** user training and a security culture where it is normal to "verify before acting".

## Practice Questions

**Q: An attacker sends a personalized email to a company's CTO, impersonating the CEO and requesting an urgent wire transfer. What technique is being used?**
Answer: **Whaling** (spear phishing targeting an executive) combined with **BEC** (executive identity impersonation).

**Q: An attacker leaves several USB drives in a company parking lot. The drives impersonate a keyboard and automatically execute commands when plugged in. What attack is this?**
Answer: **BadUSB** (HID spoofing).

**Q: A legitimate software update from a trusted vendor contains malicious code injected by attackers who compromised the build pipeline. What type of attack is this?**
Answer: **Supply chain attack**.
