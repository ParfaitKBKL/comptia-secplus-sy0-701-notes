# 2.1 - Threat Actors and Motivations

**Official CompTIA SY0-701 objective:** 2.1 - Compare and contrast common threat actors and motivations.
**Recommended resource:** Professor Messer SY0-701 - "Threat Actors", "Motivations" (Domain 2, Section 2.1)

---

## Threat Actor Types

| Actor | Sophistication | Resources | Typical Motivation |
|---|---|---|---|
| **Nation-state** | Very high | Government-funded | Espionage, sabotage, war |
| **Organized crime** | High | Well-funded | Financial gain, ransomware, extortion |
| **Hacktivist** | Medium | Varies | Political/philosophical beliefs |
| **Insider threat** | Varies | Internal access | Revenge, financial gain, ideology |
| **Unskilled attacker** (script kiddie) | Low | Minimal | Notoriety, curiosity |
| **Shadow IT** | Low-Medium | Internal | Convenience (not malicious intent) |

> **Shadow IT** is not necessarily a malicious actor but represents unsanctioned technology use that creates security gaps (e.g., employee using personal Dropbox to share work files, bypassing DLP).

---

## Actor Attributes

### Internal vs. External

| Attribute | Internal | External |
|---|---|---|
| Prior access | Yes - harder to detect | No - must establish a foothold first |
| Attack vector | Abuse of legitimate rights | Phishing, exploitation of public vulnerabilities |
| Detection risk | Lower (appears "normal") | Higher (network anomalies) |
| Potential damage | Very high (knows the environment) | Variable |

### Resources / Funding

Directly impacts attack capability:
- **Low resources:** Public tools, automated scanning, known exploits
- **Medium resources:** Adapts TTPs, some custom tooling, evades simple signatures
- **High resources:** Custom malware (implants), zero-days, long-term persistence (APT), dedicated infrastructure

### Level of Sophistication

| Level | Capabilities |
|---|---|
| **Low** | Uses known exploits, public tools (Metasploit, GitHub scripts) |
| **Medium** | Adapts TTPs, some custom tooling, evades basic detection |
| **High** | Custom malware, zero-days, supply chain attacks, multi-year operations |

## Motivations

| Motivation | Likely Actor | Real Example |
|---|---|---|
| **Data exfiltration** | Nation-state, organized crime, insider | Intellectual property theft |
| **Espionage** | Nation-state | Surveillance of critical infrastructure |
| **Service disruption** | Hacktivist, nation-state | DDoS, wiper malware |
| **Blackmail / Extortion** | Organized crime | Ransomware (double extortion) |
| **Financial gain** | Organized crime, insider | BEC fraud, cryptomining, data sales |
| **Philosophical/political beliefs** | Hacktivist | Website defacement, document leaks |
| **Ethical** | Whistleblower / gray-hat | Responsible disclosure |
| **Revenge** | Disgruntled employee (insider) | Data deletion, sabotage |
| **Disruption/chaos** | Hacktivist, script kiddie | Opportunistic attacks |
| **War / Cyber warfare** | Nation-state | Attacks on critical infrastructure |

## Advanced Persistent Threat (APT)

Nation-state or nation-state-sponsored actor characterized by:

| Characteristic | Description |
|---|---|
| **Long dwell time** | Months or even years in the network before detection |
| **Stealthy TTPs** | Living off the Land (LOLBins) - using legitimate system tools |
| **Strategic targets** | Critical infrastructure, governments, defense, healthcare |
| **Custom tooling** | Implants, specific backdoors, zero-day exploits |
| **Persistence** | Multiple persistence mechanisms to survive reboots and partial remediations |

> APT detection requires **behavioral analytics**, not just signature-based tools. An APT uses `powershell.exe` or `wmic.exe` legitimately - no malware signature to match.

## Practice Questions

**Q: An employee shares confidential files through a personal cloud service not approved by IT, to work from home more easily. What type of actor does this represent?**
Answer: **Shadow IT** - not malicious but unsanctioned behavior, creating security risks (DLP bypassed, data out of control).

**Q: A state-sponsored group of attackers compromised an organization for 18 months without detection, using only legitimate Windows tools. How is this actor classified?**
Answer: **APT (Advanced Persistent Threat)** using **Living off the Land** techniques.

**Q: What is the MAIN difference between a hacktivist and organized cybercrime?**
Answer: **Motivation**: a hacktivist is driven by ideological/political beliefs, while organized crime is driven by **financial gain**.
